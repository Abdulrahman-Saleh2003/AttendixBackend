2. خارطة الـ Endpoints (واجهات الـ REST API المتاحة):
--------------------------------------------------------------------------------

أ. وحدة الحسابات والمصادقة (/api/accounts/):
---------------------------------------------
1. POST /api/accounts/login/
   - تسجيل الدخول بالبريد الإلكتروني وكلمة المرور والحصول على JWT Access & Refresh Tokens.
2. POST /api/accounts/token/refresh/
   - تجديد التوكن (Access Token) عند انتهائه.
3. GET, PUT /api/accounts/profile/
   - استعراض وتحديث بيانات الملف الشخصي للمستخدم الحالي.
4. POST /api/accounts/change-password/
   - تغيير كلمة المرور للمستخدم المسجل دخوله.
5. GET, POST /api/accounts/superadmin/admins/
   - [خاص بالسوبر أدمن]: استعراض جميع المدراء، وإنشاء مدير (Admin) أو نائب مدير جديد.
6. GET, PATCH, DELETE /api/accounts/superadmin/admins/<id>/
   - [خاص بالسوبر أدمن]: تعديل صلاحيات المدير، تفعيله، أو إيقافه.

ب. وحدة الهيكل التنظيمي والمواقع (/api/org/):
---------------------------------------------
1. GET /api/org/available/        # جلب قائمة جميع المنشآت النشطة وأكوادها ليعرضها تطبيق الموظف
2. /api/org/departments/      (GET, POST)
3. /api/org/departments/<id>/ (GET, PUT, PATCH, DELETE)
4. /api/org/worksites/        (GET, POST)   # تحديد مواقع العمل وإحداثيات GPS ونصف القطر
5. /api/org/worksites/<id>/   (GET, PUT, PATCH, DELETE)
6. /api/org/shifts/           (GET, POST)   # تحديد الورديات ومواعيد الدوام وفترة السماح
7. /api/org/shifts/<id>/      (GET, PUT, PATCH, DELETE)

ج. وحدة الموظفين والأجهزة (/api/employees/):
---------------------------------------------
1. POST /api/employees/register/
   - تسجيل حساب موظف جديد من تطبيق الجوال.
2. GET, POST /api/employees/join-requests/
   - GET: استعراض حالة انضمام الموظف الحالية وسجل طلباته السابقة.
   - POST: إرسال طلب انضمام لمنشأة محددة عبر كودها (ممنوع إرسال طلب ثانٍ إذا كان هناك طلب معلق إلا إذا رُفض).
3. GET /api/employees/admin/join-requests/
   - [المدير]: استعراض طلبات الانضمام الواردة لمنشأته فقط (مع فلترة ?status=PENDING).
4. POST /api/employees/admin/join-requests/<id>/decide/
   - [المدير]: قبول (APPROVE) أو رفض (REJECT) انضمام الموظف مع تعليق إداري.
5. POST /api/employees/devices/register/
   - تسجيل الهاتف والمفتاح العام من التطبيق (ينشأ بحالة PENDING).
6. GET /api/employees/admin/list/
   - قائمة الموظفين للإدارة (الأدمن يرى فقط موظفي منشأته، والسوبر أدمن يرى الجميع).
7. GET, PATCH /api/employees/admin/<id>/
   - استعراض وتعديل بيانات الموظف.
8. PATCH /api/employees/admin/<id>/status/
   - [المدير]: قبول وتفعيل حساب الموظف أو رفضه أو تعليقه.
9. PATCH /api/employees/admin/devices/<id>/status/
   - [المدير]: اعتماد هاتف الموظف (ACTIVE) أو رفضه أو إلغاؤه (REVOKED).
10. /api/employees/shifts/     (GET, POST, DELETE)
   - تعيين وتعديل وردية الموظف.

د. وحدة الحضور والانصراف والطلبات (/api/attendance/):
---------------------------------------------------
1. POST /api/attendance/record/
   - تسجيل حركة البصمة (CHECK_IN, CHECK_OUT, BREAK_OUT, BREAK_IN):
     * التحقق من تفعيل الموظف واعتماد هاتفه.
     * فحص عدم التكرار (Idempotency Key).
     * فحص الموقع الجغرافي بالـ GPS ومعادلة Haversine مقارنة بنطاق موقع العمل.
     * التسجيل بوقت الخادم المعتمد حصراً.
2. GET /api/attendance/my-history/
   - استعراض سجل الحركات الشخصية للموظف عبر الموبايل.
3. GET /api/attendance/admin/records/
   - استعراض جميع حركات الحضور للمدير مع الفلترة بالموظف والتاريخ والحالة.
4. GET /api/attendance/admin/dashboard-stats/
   - إحصائيات سريعة للوحة التحكم (الحاضرون اليوم، الغائبون، الطلبات المعلقة، الأجهزة المعلقة).
5. GET, POST /api/attendance/requests/
   - تقديم طلب جديد من الموظف (مغادرة مبكرة، إجازة، تصحيح حضور، تغيير هاتف).
6. POST /api/attendance/requests/<id>/decide/
   - [المدير]: الموافقة أو الرفض على طلب الموظف مع تسجيل التعليق.
7. GET /api/attendance/admin/audit-logs/
   - [السوبر أدمن والمدير]: استعراض سجل الرقابة والتدقيق لجميع الحركات الإدارية.
