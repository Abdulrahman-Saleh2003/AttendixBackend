================================================================================
   دليل رفع مشروع «بصمتي» (Attendix) إلى GitHub وحمايته أمنياً
================================================================================

تم إعداد ملفات .gitignore تلقائياً في المشروع لضمان عدم رفع أي ملفات حساسة.

--------------------------------------------------------------------------------
المرحلة 1: أهم تنبيه أمني قبل الرفع (حماية كلمات السر والبيئة)
--------------------------------------------------------------------------------
1. ملف `.env`:
   - تم استثناؤه تلقائياً في `.gitignore`.
   - يحتوي على كلمات السر، والـ SECRET_KEY، وإيميل السوبر أدمن.
   - **لا تقم بحذف استثنائه أبداً من .gitignore**.
2. ملف `.env.example`:
   - هذا الملف مخصص للرفع إلى GitHub كنموذج عام فقط ليسترشد به من يحمّل المشروع.
3. ملف `db.sqlite3` ومجلدات الـ VirtualEnv (`Lib`, `Scripts`):
   - مستثناة تلقائياً حتى لا ترفع ملفات ضخمة أو قاعدة بيانات محلية إلى المستودع.

--------------------------------------------------------------------------------
المرحلة 2: خطوات رفع المشروع إلى مستودع GitHub لأول مرة
--------------------------------------------------------------------------------

1. افتح موجه الأوامر (PowerShell أو Terminal) داخل مسار المشروع:
   cd "D:\antigravity Projects\Attendix\AttendixBackEnd\project"
   (أو في المجلد الأب D:\antigravity Projects\Attendix إذا أردت رفع التوثيق أيضاً).

2. تهيئة مستودع Git محلي:
   git init

3. التحقق من الملفات المستثناة وتأكيد تجاهل .env:
   git status
   (تأكد من أن ملف .env أو db.sqlite3 لا يظهر ضمن الملفات ذات اللون الأخضر أو المعلقة).

4. إضافة الملفات للـ Staging:
   git add .

5. إنشاء أول Commit للمشروع:
   git commit -m "feat: Initial commit for Basmati / Attendix attendance system"

6. أنشئ مستودعاً جديداً (New Repository) على حسابك في موقع GitHub:
   - اذهب إلى: https://github.com/new
   - اختر اسماً للمستودع (مثال: attendix-backend أو basmati-attendance).
   - اجعل المستودع Private (خاص) أو Public (عام) حسب رغبتك.
   - **مهم جداً:** لا تضع إشارة صح على (Add a README) أو (.gitignore) لأننا جهزناها محلياً بالفعل.

7. ربط المستودع المحلي بمستودع GitHub:
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
   (استبدل الرابط برابط مستودعك الجديد الذي نسخته من GitHub).

8. رفع الكود (Push):
   git push -u origin main

--------------------------------------------------------------------------------
المرحلة 3: أوامر التحديث الدورية بعد أي تعديل مستقبلي
--------------------------------------------------------------------------------
عند تعديل أو إضافة أي كود جديد في المشروع:
1. git add .
2. git commit -m "وصف التعديل الذي قمت به"
3. git push

--------------------------------------------------------------------------------
المرحلة 4: كيف يقوم أي شخص (أو خادم الإنتاج) بتشغيل المشروع بعد استنساخه (Clone):
--------------------------------------------------------------------------------
1. استنساخ المستودع:
   git clone <REPO_URL>
   cd project

2. إنشاء بيئة بايثون وتفعيلها:
   python -m venv venv
   .\venv\Scripts\activate   (في Windows)
   source venv/bin/activate  (في Linux/Mac)

3. تثبيت المكتبات:
   pip install django djangorestframework djangorestframework-simplejwt django-cors-headers python-dotenv

4. تجهيز ملف البيئة:
   نسخ ملف .env.example وتسميته .env ثم تعبئة القيم المطلوبة فيه.

5. ترحيل قاعدة البيانات وإنشاء السوبر أدمن:
   python manage.py migrate
   python manage.py seed_superadmin

6. تشغيل السيرفر:
   python manage.py runserver
================================================================================
